# Streaming credential masking

`crates/polylogue/src/masking.rs` implements the fixed shared `credential-output-v1` recognition catalog through `Masker::new`, `push`, `block_boundary` and `finish`. The local synthetic [fixture](../../crates/polylogue/tests/fixtures/credential-output-v1/README.md) pins its normative source and independently authored UTF-8 extents. This module changes display bytes only. It does not classify stored content, authorize reveal or encode structured documents.

All 22 families are recognized. Contextual labels remain visible; only their secret groups are masked. URL masking preserves the scheme, final `@`, host and path, and uses the last `@` before the authority terminator. PEM suppression accepts uppercase word labels ending in `PRIVATE KEY` and continues through the first matching END or EOF. Overlapping extents form one marker; adjacent extents remain separate. Markers use `[credential: KIND, masked]` without a secret preview.

Pieces are transport boundaries and never end a match. A caller-defined block boundary ends ordinary recognizers, emits unfinished prefixes as ordinary text, and preserves active PEM suppression and partial matching END progress. Calling `finish` ends the logical value. Callers must define their logical values and handle an error as an unavailable response, rather than certifying partial output as a successful document.

The masker retains at most 512 undecided UTF-8 bytes, 2,048 regex candidates, 512 URL candidates and 512 incomplete PEM headers. Each header is limited to 512 bytes; a matching PEM END buffer is bounded by that header. Pattern definitions and Unicode tables have fixed size. It returns `io::ErrorKind::InvalidData` before accepting input that would exceed a bound. This can refuse long JWT/SendGrid initial segments, quoted CLI arguments, contextual prefixes, PEM labels or URL authorities, including passwordless authorities. Ordinary scheme text can stream because the scheme itself is preserved. A long recognized token run or PEM body does not accumulate its contents. Adversarial overlapping incomplete recognizers inside an already masked body can reach the candidate bound and explicitly refuse.

Left word boundaries use a pinned Unicode 16.0.0 table generated from Python `str.isalnum`, plus underscore. This matches the reference language's letters/numbers/underscore semantics and excludes combining marks, other connector punctuation and join controls. Unicode whitespace includes Python's U+001C–U+001F controls; explicit space/tab classes remain ASCII space/tab. Updating the Unicode version requires reviewing the table and boundary vectors together.

Every sink error is returned unchanged. Any error closes the stream, and later calls return `BrokenPipe` without touching the sink. `finish` also closes a successful stream. No output flush is requested from the sink.

The focused module tests check the 132 pinned independent cases at every single byte cut and byte chunk widths 1–8 through a UTF-8 frame decoder. Additional tests distinguish overlap from adjacency, a contextual secret extending past a PEM END, block separators, Unicode boundaries, one-character secrets, original sink errors, explicit refusal and fixed state while streaming one MiB per recognized body. They do not qualify socket/HTTP/JSON encoder composition, structured member names, reveal policy, index flags or complete production privacy acceptance.

The predecessor's preview syntax and prefix-only policy are replaced. Its lack of left boundaries for most token families, six fixed PEM labels and whole lowercase HTTP(S) credential extents conflict with the owning catalog's recognition and extent clauses. The current policy preserves scheme/host text, uses Unicode left boundaries, admits arbitrary qualifying PEM labels and suppresses complete maximal runs. No compatibility matcher remains.
