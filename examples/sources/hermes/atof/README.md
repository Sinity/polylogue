# Synthetic ATOF observer records

Handwritten neutral ATOF 0.1 scope and mark records, in the shapes the Hermes
NeMo Relay producer writes. IDs, command, output and text are synthetic; no
captured payloads were copied. UUID and phase pairs are runtime observations,
not conversations. The last record has an unreadable time and an ambiguous
default run ID on purpose; its explicit false approval and original reason
must stay exact.
