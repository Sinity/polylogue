# Morrow example archive

A week of synthetic work (Oct 01–07, 2026) on a fictional Rust library,
in Claude Code, Codex, ChatGPT and claude.ai, plus a Claude-Code-only
parents set, a live set and an annotation session. `FACTS.md` describes the
source story and counting rules; `expected/`
holds the query examples. The real-loop query tests in
`crates/polylogue/src/daemon/query/tests/morrow_examples.rs` name the
examples that still differ from current parser behavior.

The files were generated by the spec repository's
`polylogue-spec/examples/archive/build.py` (spec commit `47d55eeb`). Edit them
here directly; nothing regenerates them.

The `polylogue-testkit` crate lays them out in a temporary home where each
tool writes, runs the engine over it and imports the exports, so
tests read an archive built by the real parsers and writer.

## Tour

Run `polylogue demo tour ./morrow-tour` from an installed binary or this
checkout's build. The directory must be new. It holds the synthetic home,
archive and `transcript.md`; ordinary commands provide every displayed
answer. The public CLI test checks the search matches, two tool failures,
two children of #2, four unknown session costs and the note/context workflow.
Preparation and first-query times are separate measurements.

## Counting and cost evidence

[FACTS.md](FACTS.md) owns message identities, counting rules and cost
interpretation. Current query answers use the shipped price catalog, rather
than `prices.toml`; the tour presents those answers and does not assert the
historical example total.
